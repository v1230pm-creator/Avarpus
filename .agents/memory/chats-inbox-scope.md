---
name: Chats inbox scope
description: Defines the customer-only content boundary for the main Chats tab.
---

The main Chats tab is a customer-conversation inbox for every application role. It must show only customer profiles, names, message previews, timestamps, and unread state; repair tickets, delivery status, payments, and dealer conversations do not belong there.

**Why:** The user wants a clean communication-first experience modeled on familiar chat lists, with operational workflows kept in their own areas.

**How to apply:** Keep the bottom tab/status bar unchanged when refining this screen. Filter non-customer rooms from the list, preserve real chat data and direct chat navigation, and keep the existing E2EE-unavailable messaging visible inside conversation views.
