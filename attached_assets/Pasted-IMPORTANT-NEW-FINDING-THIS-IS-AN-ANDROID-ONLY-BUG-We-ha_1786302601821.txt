IMPORTANT NEW FINDING — THIS IS AN ANDROID-ONLY BUG

We have now confirmed the following:

- VMC Electronic BMS works correctly in the Web App/browser.
- Email input works correctly in the Web App.
- Password input works correctly in the Web App.
- The same login screen has a keyboard/focus problem ONLY in the Android APK.
- On Android APK, tapping Email/Password causes the keyboard to open and immediately close / disappear.
- This problem remains after multiple APK rebuilds.

Therefore, DO NOT treat this as a generic form validation issue.

The backend authentication is NOT the primary problem.

The problem is specifically in the Android/Expo/native rendering, keyboard, focus, WebView, or native input layer.

DO NOT simply rebuild the APK again.
