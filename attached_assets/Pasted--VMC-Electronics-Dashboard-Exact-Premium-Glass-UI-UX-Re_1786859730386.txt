# VMC Electronics Dashboard — Exact Premium Glass UI/UX Redesign

Use the attached/reference dashboard screenshot as the **PRIMARY SOURCE OF TRUTH**.

Redesign the existing VMC Electronics Dealer/Owner Dashboard to look **premium, professional, clean, modern and highly readable**, while preserving the existing information architecture.

## 1. MOST IMPORTANT RULE

DO NOT redesign the application from your imagination.

The reference screenshot must control:

* Overall layout
* Component placement
* Text hierarchy
* Card arrangement
* Navigation placement
* Icon positions
* Color family
* Spacing
* Proportions
* Content
* User flow

The redesign should look like the **same application upgraded to a premium restrained glassmorphism design**, NOT like a completely different application.

Do not remove useful existing features.

Do not add unnecessary dashboard features.

Do not introduce excessive glowing effects.

# 4. GLASS EFFECT

Every existing important box/card should use a restrained glass background.

Use approximately:

```css
background: rgba(20, 30, 48, 0.58);
backdrop-filter: blur(18px);
-webkit-backdrop-filter: blur(18px);
border: 1px solid rgba(255,255,255,0.10);
```

Use a very subtle shadow:

```css
box-shadow:
  0 8px 24px rgba(0,0,0,0.18),
  inset 0 1px 0 rgba(255,255,255,0.035);
```

IMPORTANT:

Glass must remain dark and readable.

Do NOT make the cards highly transparent.

Do NOT add strong neon outlines.

Do NOT add continuous glowing animations.

The user specifically wants a **premium professional glass effect**, not a flashy neon effect.
